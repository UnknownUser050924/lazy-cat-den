- 5–8 guesses depending on selected mode
- no exposing secret word to the guesser
- no sending secret word through shared room state in a way the wrong client can accidentally render

Result:
“猜到了 ♡”
or
“差一点！”

Next:
“换一个词”

37. GAME STATE — TECHNICAL
============================================================

Extend existing shared room state safely.

Suggested:
Room:
games: {
  activeGames: GameSession[],
  recentGames: GameHistory[]
}

GameSession:
{
  id,
  roomId,
  gameType,
  players,
  status,
  turn,
  state,
  createdAt,
  updatedAt,
  lastActionBy,
  winner?
}

Do not put an entire Room snapshot inside game state.

Use compact state.

Server must validate:
- room membership
- correct player
- correct turn
- legal move
- game completion
- no self-play
- no duplicate action
- no illegal state change

For simultaneous games:
- each player's choice stored privately server-side
- reveal only after both choices are locked

For turn games:
- only current player can move

For Bingo:
- shared square state merged safely

Preserve:
- merge
- restore
- polling
- optimistic UI
- race protection
